# Support
Status: Active
Last reviewed: 2026-10-10

## Current Offering
- Ambit is free and open source.
- There are currently no paid-only features and no priority-support promise.
- The public support routes are GitHub Issues for bugs and GitHub Releases for packaged builds and release notes.
- Optional donations open [https://vk.ru/dvoyna_studio](https://vk.ru/dvoyna_studio).

## Positioning
Use this language consistently in the app, README, and creator pages:

> Ambit is free and open source. Support is optional and helps fund development time. Donations do not unlock exclusive product features or priority support.

## Recommendation
- The in-app donation button opens https://vk.ru/dvoyna_studio.

## Maintenance Checklist
- Keep the in-app, README, and creator-page support copy aligned with the current offer.
- Keep `.github/FUNDING.yml` synced with the active funding providers.
- Keep public support routes focused on GitHub Issues for bugs and GitHub Releases for packaged builds.
- If paid support, memberships, or dedicated business contact channels are added later, update this file, the README, and the app copy together.
